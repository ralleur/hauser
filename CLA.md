## How to accept

On your first pull request, the CLA workflow in this repository posts a comment
asking you to accept this agreement. You accept by replying with the exact
sentence the comment shows:

```
I have read the Hauser Contributor License Agreement v2 and I hereby sign it
```

Your acceptance is recorded in this repository, on the `cla-signatures` branch
in `.github/cla-signatures-v2.json`, together with the pull request it was given
for. The check stays red and the pull request is not merged until it is
recorded.
