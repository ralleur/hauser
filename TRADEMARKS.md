## Reserved project identity

The following are not licensed under MIT or CC BY 4.0:

- the **Hauser** name when used to identify a software distribution or service;
- the Hauser logos and marks in `app/public/brand/` and `website/brand/`;
- the official application icons in `app/public/icons/`;
- `website/favicon.png` and `website/apple-touch-icon.png`.

No claim is made here that Hauser is a registered trademark. This policy states
the permissions granted by the project maintainer and distinguishes the freely
licensed implementation from the official project identity.

## Uses that are welcome

You may:

- refer truthfully to the original project as **Hauser**;
- say that a project is based on, compatible with or forked from Hauser;
- link to <https://github.com/ralleur/hauser>;
- use the name in commentary, reviews, tutorials and other descriptive text;
- show unmodified screenshots for discussion or documentation, subject to
  [ASSETS-LICENSE.md](ASSETS-LICENSE.md).

These uses must not imply endorsement, sponsorship or that a modified build is
an official Hauser release.

## Modified distributions

A materially modified or independently distributed build must use a different
product name and its own logo, application icons and favicon. It may describe
itself as “based on Hauser” and link to the original project.

Do not use the Hauser project identity in a domain name, package listing,
container image, hosted service or application-store listing in a way that could
reasonably be mistaken for an official distribution.

For permission beyond this policy, contact the maintainer through the repository.
