# Code of conduct

## The short version

Be decent to people. Assume good faith. Criticize work, not persons.

## What that means here

This is a small project with a small community, so this document is short on
purpose. It is not a legal instrument; it is a statement of what is expected in
issues, pull requests, and discussions.

**Expected:**

- Treat people with respect, including when you think they are wrong.
- Keep disagreement about the substance — the code, the design, the trade-off.
- Accept that "no" is a legitimate answer, and that maintainer time is finite.
- Remember that most participants are not writing in their first language.

**Not acceptable:**

- Harassment, insults, or personal attacks.
- Demeaning comments about who someone is — including but not limited to their
  gender, sexual orientation, disability, appearance, ethnicity, religion, age,
  or level of experience.
- Publishing others' private information without permission.
- Sustained disruption of discussions.

## Scope

This applies in all project spaces — issues, pull requests, discussions,
commit messages — and whenever someone is representing the project elsewhere.

## Enforcement

Report problems privately via GitHub (Security → Report a vulnerability works
for any sensitive report, or contact the maintainer directly). Reports will be
handled discreetly.

As sole maintainer I may edit, hide, or delete contributions that conflict with
this document, and may block accounts from the repository. I will explain the
reason when doing so, unless doing so would expose the person who reported it.

Because this project has exactly one maintainer, there is no appeals body. If
you believe I handled something badly, say so — but the license guarantees you
can always take the code and go your own way.
