A Home Assistant dashboard for the people at home.

Home Assistant connects the devices. Hauser gives the household an everyday interface: recognise a room, choose a scene or tap a light. You can try the actual web interface with simulated devices before installing anything.

Open the demo ↗Set up →

Free. Open source. Public beta.

Rooms instead of device lists

Start with the included room illustrations or upload your own picture. Prepared images follow the time of day and room lighting state. On the wall panel, image control lets you place devices in the picture and tap them there. Scenes and device controls stay grouped by room.

A useful wall tablet, even between touches

Standby shows a readable clock, appointments, notes and the shopping list. The web interface also adapts to a phone. The native iPhone and iPad app can pair with your Hauser server by QR code; available features differ from the web interface.

Install on the hardware you already use

Home Assistant OS users can install Hauser as a Home Assistant App. Home Assistant Container and NAS users can run the server with Docker Compose. Both paths lead to a guided setup for discovering areas and arranging rooms. Keep the server on a trusted network; remote access has its own guide.

Free software, with clear requirements

Hauser is open source and in public beta. Everyday control needs no Hauser account or subscription. You need an existing Home Assistant installation for this path. Optional image generation uses your chosen external provider and your own access; costs and limits depend on that provider. A native Apple Home connection is a separate path and needs no Home Assistant server.
