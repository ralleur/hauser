The System screen lists the settings on one page. The search finds every entry. Some sections stay hidden until you tap the logo three times.

| Group | Section | What is in it |
|---|---|---|
| Home | **Rooms & devices** | Manage rooms, create room images, central climate, reset device names and icons, reset scenes |
| Home | **Windows & motion** | Choose which contacts and detectors count |
| Home | **Notifications** | Rules per category, history, laundry setup |
| Appearance | **Interface & controls** | Appearance state, card style, interface language, control surfaces, layout reset, confirmation for Off, automatic use mode, edit PIN |
| Appearance | **Ambient & standby** | Start standby, time until standby, deep night, AI text, city map, weather, calendar in standby |
| Content | **Calendar & Reminders** | Calendars shown, reminders shown, special days for moments |
| Content | **Shopping list** | Manage shops, category order |
| Content | **Media & Music** | Library mode |
| Connections | **Services** | Home Assistant status and token, one block per module with its switch and service setup: Home, Energy, Calendar, Notes, Media, Library, Documents. Also the pairing card and remote access. |
| System | **Status & Updates** | Connection health, service health, available Home Assistant updates, license and source |
| System | **Maintenance & Diagnostics** (hidden) | Clear caches, demo mode, reload |
| Experimental | **Hotel mode**, **Guest releases** | See [Hotel mode](/hauser/docs/using/hotel-mode/) |

Without a Hauser server (for example in the static demo) the settings show only what works.
