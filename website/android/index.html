Set up

  1. First install Hauser for your existing Home Assistant. Apple Home is not available on Android.
  2. Open the APK. If asked, allow this installation from your browser or file manager, then turn that permission off again. Keep Play Protect enabled.
  3. Open Hauser, tap “Lights on” and choose Home Assistant. On your Hauser server, open System → Pair a phone. Photograph the QR code or enter the Hauser address and code manually.
  4. Pair on your trusted home network. You can then optionally choose your resident identity.

Updates and connections

Download the next APK here and install over the existing app. Do not uninstall: that preserves pairing. There are no automatic updates and this is not a store release.

You need your own reachable Hauser server. HTTP requires confirmation and is for trusted private networks only. HTTPS validates certificates fully. Remote access requires Hauser 0.50.3 or newer with the WebView session and a route that accepts device tokens and WebSockets. Upstream Access logins are not bypassed.

Android Back at the root of the web interface opens the app menu with Reload, Change connection and Fullscreen. Xiaomi handle spacing is off by default.
